# React Jobby App 💼

A job search web application built with React.js. Users can search and filter job listings based on employment type and salary range.

## 🚀 Features

* User authentication
* JWT token-based authentication
* Job search
* Filter jobs by employment type
* Filter jobs by salary range
* View user profile
* Job details
* Similar jobs
* Loading states
* API failure handling
* Retry functionality
* No jobs found state
* Protected routes

## 🛠️ Technologies Used

* React.js
* JavaScript
* CSS
* REST APIs
* JWT Authentication
* Cookies
* React Icons

## 📚 React Concepts Used

* Class Components
* State Management
* Props
* Component Lifecycle
* `componentDidMount`
* Event Handling
* Conditional Rendering
* List Rendering
* API Integration
* Authentication
* Protected Routes
* Loading and Failure States
